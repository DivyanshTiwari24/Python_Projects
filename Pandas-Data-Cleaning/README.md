#  Pandas Data Cleaning

##  Project Overview

This project demonstrates essential **data cleaning techniques** using **Python** and **Pandas**. The goal is to transform a raw, inconsistent customer call list into a clean, standardized dataset ready for data analysis and outreach.

## 🛠️ Data Cleaning Steps

-  **Data Import:** Loading Excel datasets into a Pandas DataFrame.
-  **Duplicate Removal:** Identifying and removing duplicate rows.
-  **Column Management:** Dropping unnecessary columns.
-  **String Cleaning:** Standardizing text using `strip()`, `replace()`, and Regex.
-  **Data Formatting:** Converting data types and reformatting phone numbers using lambda functions.
-  **Data Splitting:** Using `str.split()` to separate address information into individual columns.
-  **Handling Missing Values:** Managing null values using `fillna()`.
-  **Data Filtering:** Removing records based on conditions, including "Do Not Contact" requests.

##  Technologies Used

- **Language:** Python
- **Library:** Pandas
- **Environment:** Jupyter Notebook
- **Techniques:** Regex, String Manipulation, Missing Value Handling, and Index Management

##  Objective

To develop practical data cleaning skills and prepare inconsistent real-world data for reliable analysis.
