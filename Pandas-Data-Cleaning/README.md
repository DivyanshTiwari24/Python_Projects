Pandas Data Cleaning
This project demonstrates essential data cleaning techniques in Python using the Pandas library. The goal is to transform a raw, inconsistent customer call list into a clean, standardized dataset ready for analysis or outreach efforts.

Project Overview
Preparing messy data is a critical skill for any Data Analyst. This project covers the full end-to-end workflow:

Data Import: Loading Excel datasets into a Pandas DataFrame.
Duplicate Removal: Cleaning the data by dropping duplicate rows.
Column Management: Dropping unnecessary columns to improve data efficiency.
String Cleaning: Standardizing text data by removing unwanted characters using strip and replace with Regular Expressions.
Advanced Formatting: Converting data types and using Lambda functions to reformat complex phone numbers.
Data Splitting: Using str.split to separate address information into distinct columns.
Handling Nulls: Using fillna to manage missing values.
Filtering: Removing rows based on specific conditions, such as "Do Not Contact" requests.
Key Technologies
Language: Python
Library: Pandas
Techniques: Regular Expressions (Regex), String manipulation, Index management.
